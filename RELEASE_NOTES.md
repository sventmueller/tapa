Tapa 1.0.5 shows the conversation of an agent tab in a remote workspace again after a restart.

## Fixed
- After Tapa restarts, an agent tab in a remote workspace shows its earlier conversation again: Tapa reads Claude's transcript from the other computer through the workspace's connection. The tab starts once the connection is open instead of failing first.
- Codex and OpenCode tabs in a trusted workspace no longer start twice when Tapa opens.
