Tapa 1.0.7 colours the command and shows the suggestion list as you type, also without the input field.

## New
- Without the input field, the command you type gets the same colours as in the field: command, subcommands, options, variables and operators, and a dashed red underline under a command the shell cannot run. Colours your shell sets itself stay.
- Without the input field, the suggestion list opens by itself as you type a word. Return runs the line and Tab or → take the grey suggestion; once you move the selection with ↑ or ↓, they take the selected entry. Escape closes the list for that word, and Settings › Input turns it off.

## Improvements
- With only one agent installed, the toolbar's agent button opens it with one click instead of a menu.
