Tapa 1.0.8 deschide rapid fișiere din toate spațiile de lucru și arată în bara de instrumente ce rulează.

## Noutăți
- **Deschidere rapidă…** (⌘P), disponibilă și sub lupa din bara de instrumente, găsește fișiere în toate spațiile de lucru locale, precum și file și sesiuni deschise. Fișierele găsite sunt grupate după spațiul de lucru.
- Butonul **Activitate** din bara de instrumente deschide o listă actualizată în timp real cu sesiunile de agent deschise, comenzile de terminal din prim-plan și procesele gestionate. **Afișați** sare la filă sau la diviziune, **Opriți** încheie tura unui agent sau un proces gestionat.

## Îmbunătățiri
- Bara de file și butonul ei **+** rămân vizibile și cu o singură filă.
