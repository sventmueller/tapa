Tapa 1.0.4 arată în filele agenților când un spațiu de lucru nu este considerat de încredere și aplică o schimbare de încredere și agenților care rulează deja.

## Îmbunătățiri
- Într-un spațiu de lucru pe care nu l-ați considerat de încredere, fila de agent pentru Claude, Codex și OpenCode arată deasupra câmpului de introducere că configurările, skillurile, hookurile și serverele MCP ale proiectului nu sunt încărcate, cu butonul „Considerați spațiul de lucru de încredere”.
- Când considerați un spațiu de lucru de încredere sau retrageți încrederea, sesiunile de agent deschise pornesc din nou cu sau fără configurația proiectului. Își continuă conversația, iar o tură în desfășurare se încheie mai întâi.
