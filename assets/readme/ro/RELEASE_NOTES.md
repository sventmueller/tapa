Tapa 1.0.5 afișează din nou conversația unei file de agent într-un spațiu de lucru la distanță după o repornire.

## Remedieri
- După repornirea Tapa, o filă de agent într-un spațiu de lucru la distanță afișează din nou conversația anterioară: Tapa citește transcrierea Claude de pe celălalt computer prin conexiunea spațiului de lucru. Fila pornește după ce conexiunea este deschisă, în loc să eșueze mai întâi.
- Filele Codex și OpenCode dintr-un spațiu de lucru de încredere nu mai pornesc de două ori la deschiderea Tapa.
