## Codex Remote Control

Butonul pentru telefon dintr-o filă nativă Codex îți permite să asociezi telefonul și să continui pe el aceeași sesiune după încheierea rundei în curs. Funcția este disponibilă în spațiile de lucru locale de încredere.

## Performanță

Deschiderea rapidă indexează spațiile de lucru în paralel și anulează căutările vechi pe măsură ce tastezi. La restaurare, Tapa afișează întâi fila activă, apoi le încarcă pe cele ascunse. Randarea repetă mai puține operații, iar datele de intrare din terminal au prioritate când volumul ieșirii este mare.
