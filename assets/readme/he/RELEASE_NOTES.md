Tapa 1.0.6 מגן מפני Markdown שנבנה כדי למצות את הזיכרון ושומר את הפלט האחרון של תוכנית במסוף.

## תיקונים
- מסמך Markdown עם מאות אלפי תאי טבלה ריקים, בתצוגה מקדימה או בתשובה של סוכן, כבר לא גוזל שניות וג'יגה-בייטים של זיכרון: מעל 500,000 תאים ריקים הטבלאות שלו מוצגות כטקסט.
- מסוף כבר לא מחמיץ את סיום התוכנית שלו ולא מאבד את הפלט האחרון שלה כשה-Mac עמוס.

## שיפורים
- היסטוריית הסוכן משמיטה hooks שרצו בהצלחה או שעדיין רצים; hook שנכשל עדיין מוצג.
