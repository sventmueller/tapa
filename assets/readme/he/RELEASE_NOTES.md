## Codex Remote Control

כפתור הטלפון בכרטיסיית Codex המובנית מאפשר לצמד את הטלפון ולהמשיך בו את אותה הפעלה לאחר השלמת התור הנוכחי. האפשרות זמינה בסביבות עבודה מקומיות מהימנות.

## ביצועים

הפתיחה המהירה יוצרת אינדקס לסביבות העבודה במקביל ומבטלת חיפושים קודמים בזמן ההקלדה. בשחזור, Tapa מציגה תחילה את הכרטיסייה הפעילה וטוענת אחר כך את הכרטיסיות הנסתרות. התצוגה מבצעת פחות פעולות חוזרות, והקלט למסוף מקבל עדיפות כשהפלט רב.
