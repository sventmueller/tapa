Tapa 1.0.7 צובע את הפקודה ומציג את רשימת ההצעות בזמן ההקלדה, גם בלי שדה הקלט.

## חדש
- בלי שדה הקלט, הפקודה שמקלידים מקבלת את אותם צבעים כמו בשדה: פקודה, תת-פקודות, אפשרויות, משתנים ואופרטורים, וקו תחתון אדום מקווקו מתחת לפקודה שהמעטפת אינה יכולה להריץ. צבעים שהמעטפת קובעת בעצמה נשמרים.
- בלי שדה הקלט, רשימת ההצעות נפתחת מעצמה בזמן הקלדת מילה. Return מריץ את השורה, ו-Tab או → מקבלים את ההצעה האפורה; אחרי ↑ או ↓ הם מקבלים את הפריט המסומן. Esc סוגר את הרשימה עבור המילה הזו, ו„הגדרות › קלט” מכבה אותה.

## שיפורים
- כשמותקן סוכן אחד בלבד, כפתור הסוכן בסרגל הכלים פותח אותו בלחיצה אחת במקום תפריט.
