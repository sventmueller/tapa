Tapa 1.0.1 מתקנת שורות לבנות שהבהבו בתוכניות במסך מלא. Tapa 1.0.0 מתעדכנת אליה בעצמה, ו-Homebrew מתקין את אותה תמונה.

## תוקן
- תוכניות במסך מלא כמו htop כבר לא מהבהבות בשורות לבנות במראה הבהיר: Tapa מציגה את המסך שלהן לאחר שהתוכנית סיימה לכתוב אותו ולא באמצע. הקלדה בהנחיה מציגה כל מקש במהירות שהייתה קודם.
