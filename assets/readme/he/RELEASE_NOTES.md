Tapa 1.0.5 מציג שוב את השיחה של לשונית סוכן בסביבת עבודה מרוחקת אחרי הפעלה מחדש.

## תיקונים
- אחרי הפעלה מחדש של Tapa, לשונית סוכן בסביבת עבודה מרוחקת מציגה שוב את השיחה הקודמת שלה: Tapa קורא את התמליל של Claude מהמחשב האחר דרך החיבור של סביבת העבודה. הלשונית מתחילה כשהחיבור פתוח, במקום להיכשל קודם.
- לשוניות Codex ו-OpenCode בסביבת עבודה מהימנה כבר לא מופעלות פעמיים כש-Tapa נפתח.
