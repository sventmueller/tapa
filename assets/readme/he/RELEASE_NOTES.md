Tapa 1.0.2 משתמש בפחות זיכרון כשכרטיסיות נמצאות ברקע.

## שיפורים
- כרטיסיות מסוף מוסתרות משחררות את מאגרי Metal, וכרטיסיות סוכנים מוסתרות משחררות את תצוגות השיחה. הפעלות המסוף, היסטוריית הפלט והשיחות נשמרות.
- מעבר בין כרטיסיות, גלילה ושינוי גודל החלון דורשים פחות עבודה מהתהליכון הראשי. הממשק נשאר זמין גם בזמן שחזור סביבת עבודה.
- Claude ו-Codex מטפלים באופן אמין יותר בבקשות שבתור ובתשובות.
