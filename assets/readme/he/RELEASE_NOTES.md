Tapa 1.0.3 פותח סביבות עבודה במחשבים אחרים דרך SSH ומציע פקודות בזמן ההקלדה.

## חדש
- סביבות עבודה מרוחקות: „סביבת עבודה חדשה” מציעה תיקייה במחשב אחר: מארח מתוך `~/.ssh/config` או כתובת, יציאה, משתמש וסיסמה לפי הצורך, והתיקייה שם. המסופים והסוכנים שמותקנים שם רצים באותו מחשב דרך חיבור SSH אחד. אפשר לשמור סיסמה במחזיק המפתחות, ומפתח מארח לא מוכר לעולם אינו מתקבל ללא אישור. רשימת הקבצים, חלונית Git, העורך והתצוגות המקדימות אינם זמינים שם.
- סרגל הצד מציג את החיבור של סביבת עבודה מרוחקת עם „חיבור מחדש”, „התנתק” ו„ערוך חיבור”. כשחיבור שאבד חוזר, המסופים מופעלים מחדש ולשוניות הסוכנים ממשיכות את השיחה.
- הצעות בזמן ההקלדה: החל מהתו השני, שאר הפקודה המוצעת מופיע בצבע חיוור אחרי הסמן, ו-→ מקבל אותה. Tab מקבל הצעה ודאית או פותח תפריט השלמה שמתאר כל אפשרות, עם שדה הקלט או בלעדיו.
- צבעי פקודות: פקודות, תת-פקודות, אפשרויות, משתנים ואופרטורים מקבלים את צבעי ערכת הנושא, ופקודה שהמעטפת אינה יכולה להריץ מקבלת קו תחתון אדום מקווקו. „הגדרות › קלט” מכבה את ההצעות והצבעים.
- בלשונית סוכן, הכפתורים של תת-סוכנים ותהליכי רקע וגם /tasks פותחים תצוגת פעילות עם המצב וזמן הריצה של כל פריט, עם „הצגה” ו„עצירה”.

## שיפורים
- ב„הגדרות › כללי › חלון” אפשר לכבות שינוי שם של סביבת עבודה בלחיצה על שמה.
- סרגל הצד מציג את מספר הקבצים שהשתנו, את כפתור Git ואת כפתור התיקייה בסדר הזה, ואת כפתור Git רק בתוך מאגר Git.
