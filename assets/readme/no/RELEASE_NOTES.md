Tapa 1.0.1 retter hvite rader som blinket i programmer i fullskjerm. Tapa 1.0.0 oppdaterer seg selv til den, og Homebrew installerer det samme bildet.

## Rettet
- Programmer i fullskjerm som htop blinker ikke lenger med hvite rader i lyst utseende: Tapa viser skjermbildet deres når programmet er ferdig med å skrive det, ikke halvveis. Når du skriver ved en ledetekst, vises hver tast like raskt som før.
