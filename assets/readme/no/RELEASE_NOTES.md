Tapa 1.0.2 bruker mindre minne når faner ligger i bakgrunnen.

## Forbedringer
- Skjulte terminalfaner frigjør Metal-buffere, og skjulte agentfaner frigjør samtalevisningene. Terminaløkter, rullehistorikk og samtaler beholdes.
- Fanebytte, rulling og endring av vindusstørrelse belaster hovedtråden mindre. Grensesnittet reagerer også mens et arbeidsområde gjenopprettes.
- Claude og Codex håndterer forespørsler i kø og svar mer pålitelig.
