Tapa 1.0.5 знову показує розмову вкладки агента у віддаленому робочому просторі після перезапуску.

## Виправлення
- Після перезапуску Tapa вкладка агента у віддаленому робочому просторі знову показує попередню розмову: Tapa читає журнал Claude з іншого компʼютера через зʼєднання робочого простору. Вкладка запускається, щойно зʼєднання відкрите, а не спершу завершується помилкою.
- Вкладки Codex і OpenCode у довіреному робочому просторі більше не запускаються двічі під час відкриття Tapa.
