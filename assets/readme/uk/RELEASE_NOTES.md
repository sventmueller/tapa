Tapa 1.0.7 розфарбовує команду й показує список підказок під час введення, також без поля введення.

## Нове
- Без поля введення команда, яку ви вводите, отримує ті самі кольори, що й у полі: команда, підкоманди, параметри, змінні й оператори, а під командою, яку оболонка не може виконати, зʼявляється червоне пунктирне підкреслення. Кольори, які задає сама оболонка, зберігаються.
- Без поля введення список підказок відкривається сам, коли ви вводите слово. Return виконує рядок, Tab або → приймають сіру підказку; після ↑ або ↓ вони приймають вибраний елемент. Esc закриває список для цього слова, а «Параметри › Введення» вимикає його.

## Покращення
- Якщо встановлено лише одного агента, кнопка агента на панелі інструментів відкриває його одним натисканням замість меню.
