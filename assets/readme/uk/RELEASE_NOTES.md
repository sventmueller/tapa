Tapa 1.0.6 захищає від Markdown, створеного для вичерпання памʼяті, і зберігає в терміналі останній вивід програми.

## Виправлення
- Документ Markdown із сотнями тисяч порожніх клітинок таблиці в попередньому перегляді чи у відповіді агента більше не забирає секунди й гігабайти памʼяті: понад 500 000 порожніх клітинок його таблиці показуються як текст.
- Термінал більше не пропускає завершення своєї програми й не втрачає її останній вивід, коли Mac завантажений.

## Покращення
- Історія агента пропускає хуки, що виконалися успішно або ще виконуються; хук, що завершився помилкою, і далі показується.
