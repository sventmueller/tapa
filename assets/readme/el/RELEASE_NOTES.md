## Codex Remote Control

Το κουμπί τηλεφώνου σε μια εγγενή καρτέλα Codex επιτρέπει τη σύζευξη του κινητού για να συνεχίσεις εκεί την ίδια συνεδρία μόλις ολοκληρωθεί ο τρέχων γύρος. Διατίθεται σε αξιόπιστους τοπικούς χώρους εργασίας.

## Απόδοση

Το γρήγορο άνοιγμα ευρετηριάζει τους χώρους εργασίας παράλληλα και ακυρώνει τις παλιές αναζητήσεις όσο πληκτρολογείς. Κατά την επαναφορά, το Tapa δείχνει πρώτα την ενεργή καρτέλα και φορτώνει έπειτα τις κρυφές. Η σχεδίαση επαναλαμβάνει λιγότερη δουλειά και η είσοδος στο τερματικό έχει προτεραιότητα όταν η έξοδος είναι πολλή.
