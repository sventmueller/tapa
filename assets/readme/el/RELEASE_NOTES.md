Το Tapa 1.0.4 δείχνει στις καρτέλες πρακτόρων πότε ένας χώρος εργασίας δεν είναι αξιόπιστος και εφαρμόζει μια αλλαγή εμπιστοσύνης και σε πράκτορες που ήδη εκτελούνται.

## Βελτιώσεις
- Σε έναν χώρο εργασίας που δεν έχετε εμπιστευτεί, η καρτέλα πράκτορα των Claude, Codex και OpenCode δείχνει πάνω από το πεδίο εισαγωγής ότι οι ρυθμίσεις, οι δεξιότητες, τα hooks και οι διακομιστές MCP του έργου δεν έχουν φορτωθεί, με το κουμπί «Εμπιστοσύνη στον χώρο εργασίας».
- Όταν εμπιστεύεστε έναν χώρο εργασίας ή ανακαλείτε την εμπιστοσύνη, οι ανοιχτές συνεδρίες πρακτόρων του ξεκινούν ξανά με ή χωρίς τη διαμόρφωση του έργου. Συνεχίζουν τη συνομιλία τους, και μια απάντηση σε εξέλιξη ολοκληρώνεται πρώτα.
