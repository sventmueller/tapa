Το Tapa 1.0.2 χρησιμοποιεί λιγότερη μνήμη όταν υπάρχουν καρτέλες στο παρασκήνιο.

## Βελτιώσεις
- Οι κρυφές καρτέλες τερματικού αποδεσμεύουν τις ενδιάμεσες μνήμες Metal και οι κρυφές καρτέλες πρακτόρων αποδεσμεύουν τις προβολές συνομιλίας. Οι συνεδρίες τερματικού, το ιστορικό εξόδου και οι συνομιλίες διατηρούνται.
- Η εναλλαγή καρτελών, η κύλιση και η αλλαγή μεγέθους επιβαρύνουν λιγότερο το κύριο νήμα. Η διεπαφή αποκρίνεται και κατά την επαναφορά ενός χώρου εργασίας.
- Τα Claude και Codex χειρίζονται πιο αξιόπιστα τα αιτήματα σε αναμονή και τις απαντήσεις.
