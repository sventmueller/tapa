Tapa 1.0.2 zużywa mniej pamięci, gdy karty są w tle.

## Ulepszenia
- Ukryte karty terminala zwalniają bufory Metal, a ukryte karty agentów zwalniają widoki rozmów. Sesje terminala, historia przewijania i rozmowy zostają zachowane.
- Przełączanie kart, przewijanie i zmiana rozmiaru okna mniej obciążają główny wątek. Interfejs reaguje również podczas przywracania obszaru roboczego.
- Claude i Codex niezawodniej obsługują oczekujące żądania i odpowiedzi.
