Tapa 1.0.7 koloruje polecenie i pokazuje listę podpowiedzi podczas pisania, także bez pola wprowadzania.

## Nowości
- Bez pola wprowadzania wpisywane polecenie dostaje te same kolory co w polu: polecenie, podpolecenia, opcje, zmienne i operatory, a pod poleceniem, którego powłoka nie może uruchomić, pojawia się czerwone przerywane podkreślenie. Kolory ustawione przez samą powłokę pozostają.
- Bez pola wprowadzania lista podpowiedzi otwiera się sama podczas pisania słowa. Return uruchamia wiersz, a Tab lub → przyjmują szarą podpowiedź; po ↑ lub ↓ przyjmują zaznaczoną pozycję. Esc zamyka listę dla tego słowa, a „Ustawienia › Wprowadzanie” ją wyłącza.

## Ulepszenia
- Gdy zainstalowany jest tylko jeden agent, przycisk agenta na pasku narzędzi otwiera go jednym kliknięciem zamiast menu.
