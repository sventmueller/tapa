Tapa 1.0.1 naprawia białe wiersze, które migały w programach pełnoekranowych. Tapa 1.0.0 sama się do niego uaktualni, a Homebrew instaluje ten sam obraz.

## Naprawiono
- Programy pełnoekranowe, takie jak htop, nie migają już białymi wierszami w jasnym wyglądzie: Tapa pokazuje ich ekran, gdy program skończy go zapisywać, a nie w połowie. Pisanie przy znaku zachęty pokazuje każdy klawisz równie szybko jak dotąd.
