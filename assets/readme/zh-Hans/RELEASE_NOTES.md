Tapa 1.0.3 可通过 SSH 打开其他电脑上的工作区，并在你输入时建议命令。

## 新功能
- 远程工作区：“新建工作区”可以选择另一台电脑上的文件夹：来自 `~/.ssh/config` 的主机或一个地址，需要时填写端口、用户和密码，以及那里的文件夹。终端和那里安装的智能体通过同一个 SSH 连接在那台电脑上运行。密码可以保存在钥匙串中，未知的主机密钥未经确认绝不会被接受。文件列表、Git 面板、编辑器和预览在那里不可用。
- 边栏显示远程工作区的连接，并提供“重新连接”“断开连接”和“编辑连接”。断开的连接恢复后，终端会重新启动，智能体标签页会继续对话。
- 输入时的建议：从第二个字符起，建议命令的其余部分会以浅色显示在光标之后，按 → 即可采用。Tab 会采用确定的建议，或打开描述每个候选项的补全菜单，有无输入栏都可使用。
- 命令着色：命令、子命令、选项、变量和运算符使用主题颜色，shell 无法运行的命令会带红色虚线下划线。“设置 › 输入”可关闭建议和着色。
- 在智能体标签页中，子智能体和后台进程按钮以及 /tasks 会打开活动视图，显示每一项的状态和运行时间，并提供“显示”和“停止”。

## 改进
- “设置 › 通用 › 窗口”可关闭点按名称以重命名工作区。
- 边栏按此顺序显示已更改文件的数量、Git 按钮和文件夹按钮，并且只在 Git 仓库中显示 Git 按钮。
