Tapa 1.0.0 是首个以磁盘映像发布的版本：打开 `Tapa-1.0.0.dmg`，将 Tapa 拖到“应用程序”文件夹即可。Tapa 0.1.0 会自行更新到此版本，Homebrew 安装的也是同一个映像。

## 新功能
- 关闭 Tapa 的最后一个窗口会退出 Tapa 并保留一切：工作区、标签页、拆分、历史记录和智能体会话会在下次启动时恢复成你离开时的样子。只有在仍有 Shell 以外的程序在运行时，Tapa 才会先询问。
- 在边栏中拖动工作区，可按任意顺序排列；“终端”始终保持在顶部。
- 新窗口会以你最后调整过大小的窗口的尺寸和边栏宽度打开，即使 Tapa 没有恢复任何窗口也是如此；Tapa 还会记住输入栏是否显示。
- 当 Tapa 以折叠的边栏启动时，“新建工作区”按钮会保持隐藏。
- 程序成批写出的输出会在程序暂停时显示，最多延迟 8 毫秒，因此画到一半的屏幕不再闪烁。
- 每个会话都运行在 Tapa 自己的终端内核上；切换到 Alacritty 内核的设置已移除。
- 输入栏上方的文件夹和分支是纯灰色文字，与占位文字对齐。
- 在智能体标签页中，`/resume` 会列出该智能体在此文件夹中的过往会话，并在单独的标签页中继续其中一个。
- 智能体标签页浮层中的长列表会滚动，而不是让窗口变高。
- 智能体只有在空闲三秒后才算完成，因此它的状态不再在各步骤之间闪烁。
- 在全屏幕下，边栏会留在工具栏下方，并在菜单栏出现时随工具栏一起下移。

## Tapa 概览
- 边栏中的工作区，每个都有自己的标签页、拆分、智能体、编辑器和浏览器标签页；窗口和智能体会话在重启后会恢复。
- 用于 Claude、Codex、OpenCode 以及注册表中任意 ACP 智能体的智能体标签页，可在设置中安装、更新和回退到旧版本。
- 文件面板和 Git 面板，Markdown 和图片预览，支持听写的命令输入栏。
- 浅色、深色或跟随系统的外观，四种字体大小，35 种界面语言。
