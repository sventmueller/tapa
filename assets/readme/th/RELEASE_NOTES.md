Tapa 1.0.8 เปิดไฟล์จากทุกพื้นที่ทำงานได้อย่างรวดเร็ว และแสดงในแถบเครื่องมือว่ามีอะไรกำลังทำงานอยู่

## ใหม่
- **เปิดอย่างรวดเร็ว…** (⌘P) ซึ่งเปิดได้จากแว่นขยายในแถบเครื่องมือด้วย ค้นหาไฟล์ในทุกพื้นที่ทำงานในเครื่อง รวมถึงแท็บและเซสชันที่เปิดอยู่ ไฟล์ที่พบจะจัดกลุ่มตามพื้นที่ทำงาน
- ปุ่ม **กิจกรรม** ในแถบเครื่องมือเปิดรายการแบบสดของเซสชันเอเจนต์ที่เปิดอยู่ คำสั่งเทอร์มินัลที่ทำงานเบื้องหน้า และกระบวนการที่จัดการ **แสดง** จะไปยังแท็บหรือส่วนที่แบ่ง **หยุด** จะจบตาของเอเจนต์หรือกระบวนการที่จัดการ

## การปรับปรุง
- แถบแท็บและปุ่ม **+** ยังคงแสดงอยู่แม้มีแท็บเดียว
