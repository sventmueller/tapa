Tapa 1.0.4 แสดงในแท็บเอเจนต์เมื่อพื้นที่ทำงานไม่น่าเชื่อถือ และนำการเปลี่ยนแปลงความเชื่อถือไปใช้กับเอเจนต์ที่ทำงานอยู่แล้วด้วย

## การปรับปรุง
- ในพื้นที่ทำงานที่คุณยังไม่เชื่อถือ แท็บเอเจนต์ของ Claude, Codex และ OpenCode จะแสดงเหนือช่องป้อนข้อมูลว่ายังไม่ได้โหลดการตั้งค่า Skills, hooks และเซิร์ฟเวอร์ MCP ของโปรเจกต์ พร้อมปุ่ม "เชื่อถือพื้นที่ทำงาน"
- เมื่อคุณเชื่อถือพื้นที่ทำงานหรือยกเลิกความเชื่อถือ เซสชันเอเจนต์ที่เปิดอยู่จะเริ่มใหม่โดยมีหรือไม่มีการกำหนดค่าของโปรเจกต์ เซสชันจะสนทนาต่อ และรอบที่กำลังทำงานอยู่จะจบก่อน
