## การปรับปรุง
- แท็บเทอร์มินัลที่ซ่อนอยู่จะคืนบัฟเฟอร์ Metal และแท็บเอเจนต์ที่ซ่อนอยู่จะคืนหน่วยความจำที่ใช้แสดงการสนทนา เซสชันเทอร์มินัล ประวัติเอาต์พุต และการสนทนายังคงอยู่
- การสลับแท็บ การเลื่อน และการปรับขนาดหน้าต่างลดภาระของเธรดหลัก อินเทอร์เฟซยังตอบสนองขณะกู้คืนพื้นที่ทำงาน
- Claude และ Codex จัดการคำขอในคิวและการตอบกลับได้เสถียรขึ้น
