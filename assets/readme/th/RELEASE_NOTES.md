Tapa 1.0.5 แสดงบทสนทนาของแท็บเอเจนต์ในพื้นที่ทำงานระยะไกลอีกครั้งหลังเริ่มใหม่

## การแก้ไข
- หลังจาก Tapa เริ่มใหม่ แท็บเอเจนต์ในพื้นที่ทำงานระยะไกลจะแสดงบทสนทนาก่อนหน้าอีกครั้ง โดย Tapa อ่านบันทึกการสนทนาของ Claude จากคอมพิวเตอร์อีกเครื่องผ่านการเชื่อมต่อของพื้นที่ทำงาน แท็บจะเริ่มเมื่อการเชื่อมต่อเปิดแล้ว แทนที่จะล้มเหลวก่อน
- แท็บ Codex และ OpenCode ในพื้นที่ทำงานที่เชื่อถือจะไม่เริ่มสองครั้งเมื่อเปิด Tapa อีกต่อไป
