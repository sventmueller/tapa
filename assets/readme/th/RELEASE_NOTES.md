Tapa 1.0.7 ใส่สีให้คำสั่งและแสดงรายการคำแนะนำขณะพิมพ์ แม้ไม่มีช่องป้อนข้อมูล

## มีอะไรใหม่
- เมื่อไม่มีช่องป้อนข้อมูล คำสั่งที่คุณพิมพ์จะได้สีเดียวกับในช่อง ได้แก่ คำสั่ง คำสั่งย่อย ตัวเลือก ตัวแปร และตัวดำเนินการ พร้อมเส้นใต้สีแดงแบบประใต้คำสั่งที่เชลล์เรียกใช้ไม่ได้ สีที่เชลล์ตั้งเองยังคงอยู่
- เมื่อไม่มีช่องป้อนข้อมูล รายการคำแนะนำจะเปิดขึ้นเองขณะที่คุณพิมพ์คำ Return จะเรียกใช้บรรทัด และ Tab หรือ → จะรับคำแนะนำสีเทา หลังจากกด ↑ หรือ ↓ ปุ่มเหล่านี้จะรับรายการที่เลือก Esc จะปิดรายการสำหรับคำนั้น และ "การตั้งค่า › การป้อนข้อมูล" จะปิดฟีเจอร์นี้

## การปรับปรุง
- เมื่อติดตั้งเอเจนต์ไว้เพียงตัวเดียว ปุ่มเอเจนต์บนแถบเครื่องมือจะเปิดเอเจนต์นั้นด้วยการคลิกครั้งเดียวแทนเมนู
