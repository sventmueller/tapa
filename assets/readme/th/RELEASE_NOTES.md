Tapa 1.0.1 แก้ปัญหาแถวสีขาวกะพริบในโปรแกรมแบบเต็มหน้าจอ Tapa 1.0.0 จะอัปเดตตัวเองเป็นรุ่นนี้ และ Homebrew ก็ติดตั้งอิมเมจเดียวกัน

## แก้ไขแล้ว
- โปรแกรมแบบเต็มหน้าจออย่าง htop จะไม่กะพริบเป็นแถวสีขาวในหน้าตาแบบสว่างอีกต่อไป: Tapa จะแสดงหน้าจอของโปรแกรมเมื่อโปรแกรมเขียนเสร็จแล้ว ไม่ใช่ตอนที่เขียนไปได้ครึ่งเดียว การพิมพ์ที่พรอมต์ยังแสดงแต่ละปุ่มได้เร็วเท่าเดิม
