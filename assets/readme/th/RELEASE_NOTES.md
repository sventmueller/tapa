Tapa 1.0.3 เปิดพื้นที่ทำงานบนคอมพิวเตอร์เครื่องอื่นผ่าน SSH และแนะนำคำสั่งขณะที่คุณพิมพ์

## มีอะไรใหม่
- พื้นที่ทำงานระยะไกล: "พื้นที่ทำงานใหม่" ให้เลือกโฟลเดอร์บนคอมพิวเตอร์เครื่องอื่นได้ โดยระบุโฮสต์จาก `~/.ssh/config` หรือที่อยู่ พอร์ต ผู้ใช้ และรหัสผ่านเมื่อจำเป็น และโฟลเดอร์ที่นั่น เทอร์มินัลและเอเจนต์ที่ติดตั้งไว้ที่นั่นจะทำงานบนคอมพิวเตอร์เครื่องนั้นผ่านการเชื่อมต่อ SSH เพียงหนึ่งเดียว รหัสผ่านเก็บไว้ในพวงกุญแจได้ และจะไม่ยอมรับคีย์โฮสต์ที่ไม่รู้จักโดยไม่ได้รับการยืนยัน รายการไฟล์ แผง Git ตัวแก้ไข และการแสดงตัวอย่างจะใช้ที่นั่นไม่ได้
- แถบด้านข้างแสดงการเชื่อมต่อของพื้นที่ทำงานระยะไกลพร้อม "เชื่อมต่อใหม่" "ตัดการเชื่อมต่อ" และ "แก้ไขการเชื่อมต่อ" เมื่อการเชื่อมต่อที่ขาดไปกลับมา เทอร์มินัลจะเริ่มใหม่และแท็บเอเจนต์จะสนทนาต่อ
- คำแนะนำขณะพิมพ์: ตั้งแต่อักขระที่สอง ส่วนที่เหลือของคำสั่งที่แนะนำจะแสดงจาง ๆ หลังเคอร์เซอร์ และ → จะรับคำแนะนำนั้น Tab จะรับคำแนะนำที่แน่นอน หรือเปิดเมนูเติมคำที่อธิบายตัวเลือกแต่ละรายการ ทั้งเมื่อมีและไม่มีช่องป้อนข้อมูล
- สีของคำสั่ง: คำสั่ง คำสั่งย่อย ตัวเลือก ตัวแปร และตัวดำเนินการจะใช้สีของธีม และคำสั่งที่เชลล์เรียกใช้ไม่ได้จะมีเส้นใต้สีแดงแบบประ "การตั้งค่า › การป้อนข้อมูล" ปิดคำแนะนำและสีได้
- ในแท็บเอเจนต์ ปุ่มสำหรับเอเจนต์ย่อยและกระบวนการเบื้องหลัง รวมถึง /tasks จะเปิดมุมมองกิจกรรมที่แสดงสถานะและเวลาทำงานของแต่ละรายการ พร้อม "แสดง" และ "หยุด"

## การปรับปรุง
- "การตั้งค่า › ทั่วไป › หน้าต่าง" ปิดการเปลี่ยนชื่อพื้นที่ทำงานโดยคลิกที่ชื่อได้
- แถบด้านข้างแสดงจำนวนไฟล์ที่เปลี่ยนแปลง ปุ่ม Git และปุ่มโฟลเดอร์ตามลำดับนี้ และแสดงปุ่ม Git เฉพาะภายในที่เก็บ Git
