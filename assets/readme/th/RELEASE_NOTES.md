Tapa 1.0.6 ป้องกัน Markdown ที่สร้างมาเพื่อใช้หน่วยความจำจนหมด และเก็บเอาต์พุตสุดท้ายของโปรแกรมไว้ในเทอร์มินัล

## การแก้ไข
- เอกสาร Markdown ที่มีเซลล์ตารางว่างหลายแสนเซลล์ ไม่ว่าในตัวอย่างหรือในคำตอบของเอเจนต์ จะไม่ใช้เวลาหลายวินาทีและหน่วยความจำหลายกิกะไบต์อีกต่อไป เมื่อเกิน 500,000 เซลล์ว่าง ตารางจะแสดงเป็นข้อความ
- เทอร์มินัลจะไม่พลาดการสิ้นสุดของโปรแกรมหรือสูญเสียเอาต์พุตสุดท้ายของโปรแกรมอีกต่อไปเมื่อ Mac ทำงานหนัก

## การปรับปรุง
- ประวัติของเอเจนต์จะไม่แสดง hook ที่ทำงานสำเร็จหรือยังทำงานอยู่ ส่วน hook ที่ล้มเหลวยังคงแสดง
