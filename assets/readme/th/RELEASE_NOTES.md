Tapa 1.0.0 เป็นรุ่นแรกที่เผยแพร่เป็นดิสก์อิมเมจ: เปิด `Tapa-1.0.0.dmg` แล้วลาก Tapa ไปวางบนโฟลเดอร์แอปพลิเคชัน Tapa 0.1.0 จะอัปเดตตัวเองเป็นรุ่นนี้ และ Homebrew ก็ติดตั้งอิมเมจเดียวกัน

## มีอะไรใหม่
- การปิดหน้าต่างสุดท้ายของ Tapa จะปิด Tapa และเก็บทุกอย่างไว้: พื้นที่ทำงาน แถบ การแบ่งบาน ประวัติ และเซสชันของเอเจนต์จะกลับมาเมื่อเปิดครั้งถัดไปตามที่คุณทิ้งไว้ Tapa จะถามก่อนเฉพาะเมื่อยังมีโปรแกรมอื่นที่ไม่ใช่เชลล์ทำงานอยู่
- ลากพื้นที่ทำงานในแถบด้านข้างให้เรียงลำดับอย่างไรก็ได้ "เทอร์มินัล" จะอยู่บนสุดเสมอ
- หน้าต่างใหม่จะเปิดด้วยขนาดและความกว้างแถบด้านข้างของหน้าต่างที่คุณปรับขนาดล่าสุด แม้ในกรณีที่ Tapa ไม่ได้คืนค่าหน้าต่างใดเลย และ Tapa จะจำว่าช่องป้อนข้อมูลแสดงอยู่หรือไม่
- เมื่อ Tapa เริ่มทำงานโดยที่แถบด้านข้างยุบอยู่ ปุ่ม "พื้นที่ทำงานใหม่" จะยังคงซ่อนอยู่
- เอาต์พุตที่โปรแกรมเขียนออกมาเป็นชุดใหญ่จะแสดงเมื่อโปรแกรมหยุดพัก ช้าที่สุดไม่เกิน 8 มิลลิวินาทีหลังจากนั้น หน้าจอที่วาดค้างครึ่งหนึ่งจึงไม่กะพริบอีกต่อไป
- ทุกเซสชันทำงานบนแกนเทอร์มินัลของ Tapa เอง และการตั้งค่าที่เคยสลับไปใช้แกนของ Alacritty ถูกนำออกแล้ว
- โฟลเดอร์และบรานช์เหนือช่องป้อนข้อมูลเป็นข้อความสีเทาธรรมดา จัดแนวตรงกับข้อความตัวอย่าง
- ในแถบเอเจนต์ `/resume` จะแสดงรายการเซสชันที่ผ่านมาของเอเจนต์ในโฟลเดอร์นี้ และเปิดเซสชันที่เลือกต่อในแถบของตัวเอง
- รายการยาวในโอเวอร์เลย์ของแถบเอเจนต์จะเลื่อนได้ แทนที่จะทำให้หน้าต่างสูงขึ้น
- เอเจนต์จะถือว่าเสร็จสิ้นก็ต่อเมื่อว่างเว้นครบสามวินาที สถานะจึงไม่กะพริบระหว่างขั้นตอนอีกต่อไป
- ในแบบเต็มหน้าจอ แถบด้านข้างจะอยู่ใต้แถบเครื่องมือ และเลื่อนลงพร้อมกันเมื่อแถบเมนูปรากฏ

## ภาพรวมของ Tapa
- พื้นที่ทำงานในแถบด้านข้าง แต่ละแห่งมีแถบ การแบ่งบาน เอเจนต์ ตัวแก้ไข และแถบเบราว์เซอร์ของตัวเอง หน้าต่างและเซสชันของเอเจนต์จะกลับมาหลังรีสตาร์ท
- แถบเอเจนต์สำหรับ Claude, Codex, OpenCode และเอเจนต์ ACP ใดก็ได้จากรีจิสทรี ติดตั้ง อัปเดต และย้อนกลับไปรุ่นก่อนหน้าได้จากการตั้งค่า
- แผงไฟล์และ Git การแสดงตัวอย่าง Markdown และรูปภาพ และช่องป้อนคำสั่งพร้อมการป้อนตามคำบอก
- หน้าตาแบบสว่าง มืด หรือตามระบบ ขนาดตัวอักษรสี่ขนาด และอินเทอร์เฟซ 35 ภาษา
