## Codex Remote Control

ปุ่มโทรศัพท์ในแท็บ Codex แบบเนทีฟช่วยให้จับคู่โทรศัพท์และใช้งานเซสชันเดิมต่อบนโทรศัพท์ได้เมื่อรอบปัจจุบันสิ้นสุด ใช้ได้ในพื้นที่ทำงานภายในเครื่องที่เชื่อถือได้

## ประสิทธิภาพ

การเปิดด่วนสร้างดัชนีพื้นที่ทำงานพร้อมกันและยกเลิกการค้นหาเก่าขณะพิมพ์ เมื่อกู้คืนเซสชัน Tapa จะแสดงแท็บที่ใช้งานอยู่ก่อนแล้วจึงโหลดแท็บที่ซ่อนอยู่ การแสดงผลทำงานซ้ำน้อยลง และให้ความสำคัญกับอินพุตของเทอร์มินัลเมื่อมีเอาต์พุตจำนวนมาก
