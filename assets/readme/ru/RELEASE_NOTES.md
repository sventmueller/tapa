## Codex Remote Control

Кнопка телефона в нативной вкладке Codex позволяет подключить телефон и продолжить на нём тот же сеанс после завершения текущего хода. Функция доступна в доверенных локальных рабочих пространствах.

## Производительность

Быстрое открытие индексирует рабочие пространства параллельно и отменяет устаревшие поиски по мере ввода. При восстановлении Tapa сначала показывает активную вкладку, а затем загружает скрытые. Отрисовка выполняет меньше повторных операций, а при большом объёме вывода приоритет получает ввод в терминале.
