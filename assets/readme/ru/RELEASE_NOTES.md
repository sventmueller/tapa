Tapa 1.0.7 раскрашивает команду и показывает список подсказок при вводе, в том числе без поля ввода.

## Новое
- Без поля ввода набираемая команда получает те же цвета, что и в поле: команда, подкоманды, параметры, переменные и операторы, а под командой, которую оболочка не может выполнить, появляется красное пунктирное подчёркивание. Цвета, которые задаёт сама оболочка, сохраняются.
- Без поля ввода список подсказок открывается сам, пока вы набираете слово. Return выполняет строку, Tab или → принимают серую подсказку; после ↑ или ↓ они принимают выбранный элемент. Esc закрывает список для этого слова, а «Настройки › Ввод» отключают его.

## Улучшения
- Если установлен только один агент, кнопка агента на панели инструментов открывает его одним нажатием вместо меню.
