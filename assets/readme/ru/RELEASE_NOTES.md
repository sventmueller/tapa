Tapa 1.0.5 снова показывает разговор вкладки агента в удалённой рабочей области после перезапуска.

## Исправления
- После перезапуска Tapa вкладка агента в удалённой рабочей области снова показывает прежний разговор: Tapa читает журнал Claude с другого компьютера через подключение рабочей области. Вкладка запускается, когда подключение открыто, а не сначала завершается ошибкой.
- Вкладки Codex и OpenCode в доверенной рабочей области больше не запускаются дважды при открытии Tapa.
