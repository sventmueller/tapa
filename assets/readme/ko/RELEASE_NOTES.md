Tapa 1.0.6은 메모리를 고갈시키도록 만든 Markdown으로부터 보호하고, 터미널에 프로그램의 마지막 출력을 유지합니다.

## 수정 사항
- 수십만 개의 빈 표 셀이 있는 Markdown 문서는 미리보기나 에이전트의 응답에서도 더 이상 몇 초와 수 기가바이트의 메모리를 소모하지 않습니다. 빈 셀이 500,000개를 넘으면 표가 텍스트로 표시됩니다.
- Mac이 바쁠 때도 터미널이 더 이상 프로그램의 종료를 놓치거나 마지막 출력을 잃지 않습니다.

## 개선 사항
- 에이전트 기록에서 정상적으로 실행되었거나 아직 실행 중인 훅은 표시되지 않으며, 실패한 훅은 계속 표시됩니다.
