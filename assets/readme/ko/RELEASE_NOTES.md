Tapa 1.0.7은 입력 필드 없이도 입력하는 동안 명령에 색을 입히고 제안 목록을 보여 줍니다.

## 새로운 기능
- 입력 필드 없이도 입력한 명령이 필드와 같은 색으로 표시됩니다. 명령, 하위 명령, 옵션, 변수, 연산자에 색이 입혀지고, 셸이 실행할 수 없는 명령에는 빨간 점선 밑줄이 그어집니다. 셸이 직접 지정한 색은 그대로 유지됩니다.
- 입력 필드 없이도 단어를 입력하면 제안 목록이 저절로 열립니다. Return은 줄을 실행하고 Tab 또는 →는 회색 제안을 받아들이며, ↑ 또는 ↓로 선택을 옮긴 뒤에는 선택한 항목을 받아들입니다. Esc는 그 단어에 대한 목록을 닫고, '설정 › 입력'에서 끌 수 있습니다.

## 개선 사항
- 에이전트가 하나만 설치되어 있으면 도구 막대의 에이전트 버튼이 메뉴 대신 한 번의 클릭으로 그것을 엽니다.
