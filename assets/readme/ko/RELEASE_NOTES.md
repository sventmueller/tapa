Tapa 1.0.4는 작업 공간을 신뢰하지 않을 때 에이전트 탭에 이를 표시하고, 신뢰 변경을 이미 실행 중인 에이전트에도 적용합니다.

## 개선 사항
- 신뢰하지 않은 작업 공간에서는 Claude, Codex, OpenCode의 에이전트 탭 입력 필드 위에 프로젝트의 설정, 스킬, 훅, MCP 서버를 불러오지 않았다는 안내가 '작업 공간 신뢰' 버튼과 함께 표시됩니다.
- 작업 공간을 신뢰하거나 신뢰를 취소하면 열려 있는 에이전트 세션이 프로젝트 구성을 포함하거나 제외한 채 다시 시작됩니다. 대화는 이어지며, 진행 중인 턴은 먼저 끝납니다.
