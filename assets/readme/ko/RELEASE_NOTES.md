Tapa 1.0.3는 SSH를 통해 다른 컴퓨터의 작업 공간을 열고, 입력하는 동안 명령을 제안합니다.

## 새로운 기능
- 원격 작업 공간: '새로운 작업 공간'에서 다른 컴퓨터의 폴더를 선택할 수 있습니다. `~/.ssh/config`의 호스트나 주소, 필요하면 포트, 사용자, 암호, 그리고 그곳의 폴더를 지정합니다. 터미널과 그곳에 설치된 에이전트는 하나의 SSH 연결을 통해 그 컴퓨터에서 실행됩니다. 암호는 키체인에 보관할 수 있으며, 알 수 없는 호스트 키는 확인 없이 절대 수락되지 않습니다. 파일 목록, Git 패널, 편집기, 미리보기는 그곳에서 사용할 수 없습니다.
- 사이드바에 원격 작업 공간의 연결 상태가 '다시 연결', '연결 해제', '연결 편집'과 함께 표시됩니다. 끊긴 연결이 돌아오면 터미널이 다시 시작되고 에이전트 탭은 대화를 이어 갑니다.
- 입력 중 제안: 두 번째 문자부터 제안된 명령의 나머지가 커서 뒤에 흐리게 나타나고, →로 받아들입니다. Tab은 확실한 제안을 받아들이거나 각 후보를 설명하는 완성 메뉴를 엽니다. 입력 필드가 있든 없든 동작합니다.
- 명령 색상: 명령, 하위 명령, 옵션, 변수, 연산자가 테마 색상으로 표시되고, 셸이 실행할 수 없는 명령에는 빨간 점선 밑줄이 그어집니다. '설정 › 입력'에서 제안과 색상을 끌 수 있습니다.
- 에이전트 탭에서 하위 에이전트와 백그라운드 프로세스 버튼, 그리고 /tasks는 각 항목의 상태와 실행 시간을 '보기', '중단'과 함께 보여 주는 활동 보기를 엽니다.

## 개선 사항
- '설정 › 일반 › 윈도우'에서 이름을 클릭하여 작업 공간 이름을 변경하는 기능을 끌 수 있습니다.
- 사이드바에 변경된 파일 수, Git 버튼, 폴더 버튼이 이 순서로 표시되며, Git 버튼은 Git 저장소 안에서만 표시됩니다.
