Tapa 1.0.8은 모든 작업 공간의 파일을 빠르게 열고, 실행 중인 항목을 도구 막대에 보여 줍니다.

## 새로운 기능
- **빠르게 열기…**(⌘P)는 도구 막대의 돋보기로도 열 수 있으며, 모든 로컬 작업 공간의 파일과 열려 있는 탭 및 세션을 찾습니다. 찾은 파일은 작업 공간별로 묶여 표시됩니다.
- 도구 막대의 **활동** 버튼은 열려 있는 에이전트 세션, 포그라운드 터미널 명령, 관리되는 프로세스의 실시간 목록을 엽니다. **보기**는 해당 탭이나 분할로 이동하고, **중단**은 에이전트의 차례나 관리되는 프로세스를 끝냅니다.

## 개선 사항
- 탭이 하나뿐이어도 탭 막대와 **+**가 계속 보입니다.
