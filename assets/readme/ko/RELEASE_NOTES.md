Tapa 1.0.0은 디스크 이미지로 나오는 첫 번째 릴리스입니다. `Tapa-1.0.0.dmg`를 열고 Tapa를 응용 프로그램 폴더로 드래그하십시오. Tapa 0.1.0은 스스로 이 버전으로 업데이트되며, Homebrew도 같은 이미지를 설치합니다.

## 새로운 기능
- Tapa의 마지막 창을 닫으면 Tapa가 종료되며 모든 것을 보존합니다. 작업 공간, 탭, 분할, 기록, 에이전트 세션이 다음에 시작할 때 떠난 그대로 돌아옵니다. Tapa는 셸이 아닌 프로그램이 아직 실행 중일 때만 먼저 묻습니다.
- 사이드바에서 작업 공간을 원하는 순서로 드래그할 수 있으며, '터미널'은 항상 맨 위에 남습니다.
- 새 창은 마지막으로 크기를 바꾼 창의 크기와 사이드바 너비로 열립니다. Tapa가 창을 복원하지 않을 때도 마찬가지이며, 입력 필드를 표시하는지 여부도 기억합니다.
- 사이드바를 접은 상태로 Tapa를 시작하면 새로운 작업 공간 버튼이 숨겨진 채로 남습니다.
- 프로그램이 한꺼번에 쓴 출력은 프로그램이 잠시 멈추면 늦어도 8ms 뒤에 표시되므로, 반쯤 그려진 화면이 더 이상 깜박이지 않습니다.
- 모든 세션이 Tapa 자체 터미널 코어에서 실행되며, Alacritty 코어로 전환하던 설정은 사라졌습니다.
- 입력 필드 위의 폴더와 브랜치는 플레이스홀더에 맞춰 정렬된 일반 회색 텍스트입니다.
- 에이전트 탭에서 `/resume`은 이 폴더에 있는 에이전트의 지난 세션을 나열하고 그중 하나를 전용 탭에서 이어 갑니다.
- 에이전트 탭 오버레이의 긴 목록은 윈도우를 키우는 대신 스크롤됩니다.
- 에이전트는 3초 동안 유휴 상태가 이어져야 끝난 것으로 간주되므로, 단계 사이에 상태가 더 이상 깜박이지 않습니다.
- 전체 화면에서 사이드바는 도구 막대 아래에 머물고, 메뉴 막대가 나타나면 도구 막대와 함께 아래로 내려옵니다.

## Tapa 한눈에 보기
- 사이드바의 작업 공간마다 탭, 분할, 에이전트, 편집기, 브라우저 탭이 있으며, 창과 에이전트 세션은 다시 시작한 뒤에도 돌아옵니다.
- Claude, Codex, OpenCode 및 레지스트리의 모든 ACP 에이전트를 위한 에이전트 탭. 설치, 업데이트, 이전 버전으로 되돌리기는 설정에서 합니다.
- 파일 패널과 Git 패널, Markdown 및 그림 미리보기, 받아쓰기를 지원하는 명령 입력 필드.
- 라이트, 다크 또는 시스템 화면 모양, 네 가지 글꼴 크기, 35개 인터페이스 언어.
