Tapa 1.0.8 は、すべてのワークスペースのファイルをすばやく開き、実行中のものをツールバーに表示します。

## 新機能
- **クイックオープン…**（⌘P）はツールバーの虫めがねからも開き、すべてのローカルワークスペースのファイルと、開いているタブやセッションを見つけます。見つかったファイルはワークスペースごとにまとめて表示されます。
- ツールバーの**アクティビティ**ボタンは、開いているエージェントのセッション、フォアグラウンドのターミナルコマンド、管理対象のプロセスをリアルタイムで一覧表示します。**表示**でそのタブや分割に移動し、**停止**でエージェントのターンや管理対象のプロセスを終了します。

## 改善
- タブが1つだけでも、タブバーとその **+** が表示されたままになります。
