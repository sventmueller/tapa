Tapa 1.0.0 は、ディスクイメージで配布する最初のリリースです。`Tapa-1.0.0.dmg` を開いて、Tapa をアプリケーションフォルダにドラッグしてください。Tapa 0.1.0 は自動でこのバージョンにアップデートされ、Homebrew も同じイメージをインストールします。

## 新機能
- Tapa の最後のウインドウを閉じると Tapa は終了し、すべてを保持します。ワークスペース、タブ、分割、履歴、エージェントのセッションは、次回の起動時に終了前の状態のまま戻ります。Tapa が先に確認するのは、シェル以外のプログラムがまだ実行中のときだけです。
- サイドバーでワークスペースをドラッグして好きな順に並べ替えられます。「ターミナル」は常に一番上に残ります。
- 新しいウインドウは、最後にサイズを変えたウインドウの大きさとサイドバーの幅で開きます。Tapa がウインドウを復元しない場合も同様です。また、入力フィールドを表示しているかどうかも記憶します。
- サイドバーを折りたたんだ状態で Tapa を起動すると、「新規ワークスペース」ボタンは表示されないままになります。
- プログラムがまとめて書き出した出力は、プログラムが一息ついた時点で、遅くとも 8 ms 後に表示されるため、描画途中の画面がちらつかなくなりました。
- すべてのセッションが Tapa 独自のターミナルコアで動作します。Alacritty のコアに切り替える設定は廃止されました。
- 入力フィールドの上のフォルダとブランチは、プレースホルダーに揃えた無地のグレーのテキストで表示されます。
- エージェントタブで `/resume` を使うと、このフォルダにあるエージェントの過去のセッションが一覧表示され、選んだ1つが専用のタブで再開されます。
- エージェントタブのオーバーレイに表示される長いリストは、ウインドウを高くせずにスクロールします。
- エージェントは3秒間アイドル状態が続いてはじめて完了と見なされるため、ステップの合間にステータスがちらつかなくなりました。
- フルスクリーンでは、サイドバーはツールバーの下に留まり、メニューバーが表示されるとツールバーと一緒に下へスライドします。

## Tapa の概要
- サイドバーに並ぶワークスペース。それぞれにタブ、分割、エージェント、エディタ、ブラウザタブがあり、ウインドウとエージェントのセッションは再起動後も元に戻ります。
- Claude、Codex、OpenCode、そしてレジストリにある任意の ACP エージェントのためのエージェントタブ。インストール、アップデート、以前のバージョンへの切り戻しは設定から行えます。
- ファイルパネルと Git パネル、Markdown と画像のプレビュー、音声入力に対応したコマンド入力フィールド。
- ライト、ダーク、システムに合わせた外観、4 つのフォントサイズ、35 のインターフェイス言語。
