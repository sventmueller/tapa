Tapa 1.0.3 では、SSH 経由でほかのコンピュータ上のワークスペースを開けるようになり、入力中にコマンドを提案します。

## 新機能
- リモートワークスペース：「新規ワークスペース」で、ほかのコンピュータ上のフォルダを選べます。`~/.ssh/config` のホストまたはアドレス、必要に応じてポート、ユーザ、パスワード、そしてそこのフォルダを指定します。ターミナルとそこにインストールされたエージェントは、1 本の SSH 接続を通じてそのコンピュータ上で動作します。パスワードはキーチェーンに保存でき、不明なホスト鍵が確認なしに受け入れられることはありません。ファイルリスト、Git パネル、エディタ、プレビューはそこでは使えません。
- サイドバーにはリモートワークスペースの接続状態が表示され、「再接続」「接続を解除」「接続を編集」を選べます。切れた接続が戻ると、ターミナルが再び起動し、エージェントタブは会話を続けます。
- 入力中の提案：2 文字目から、提案されたコマンドの残りがカーソルの後ろに薄く表示され、→ で受け入れられます。Tab は確かな提案を受け入れるか、各候補の説明付きの補完メニューを開きます。入力フィールドの有無にかかわらず使えます。
- コマンドの色分け：コマンド、サブコマンド、オプション、変数、演算子にテーマの色が付き、シェルが実行できないコマンドには赤い破線の下線が付きます。「設定 › 入力」で提案と色分けをオフにできます。
- エージェントタブでは、サブエージェントとバックグラウンドプロセスのボタン、および /tasks で、各項目の状態と実行時間を「表示」「停止」とともに示すアクティビティビューが開きます。

## 改善点
- 「設定 › 一般 › ウインドウ」で、名前をクリックしてワークスペース名を変更する機能をオフにできます。
- サイドバーには、変更されたファイルの数、Git ボタン、フォルダボタンの順に表示され、Git ボタンは Git リポジトリ内でのみ表示されます。
