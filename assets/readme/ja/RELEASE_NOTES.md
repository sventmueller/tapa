Tapa 1.0.6 では、メモリを使い果たすよう作られた Markdown から保護し、ターミナルにプログラムの最後の出力を残します。

## 修正点
- 数十万個の空の表セルを含む Markdown 書類は、プレビューやエージェントの返答の中でも、もう数秒と数ギガバイトのメモリを消費しません。空のセルが 500,000 個を超えると、表はテキストとして表示されます。
- Mac が混み合っていても、ターミナルがプログラムの終了を見逃したり、最後の出力を失ったりすることはなくなりました。

## 改善点
- エージェントの履歴には、正常に終了したフックや実行中のフックは表示されなくなりました。失敗したフックは引き続き表示されます。
