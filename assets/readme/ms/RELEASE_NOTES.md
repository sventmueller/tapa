## Codex Remote Control

Butang telefon dalam tab Codex asli membolehkan anda menggandingkan telefon dan menyambung sesi yang sama di telefon selepas giliran semasa selesai. Tersedia dalam ruang kerja setempat yang dipercayai.

## Prestasi

Buka Pantas mengindeks ruang kerja secara selari dan membatalkan carian lama semasa anda menaip. Ketika memulihkan sesi, Tapa memaparkan tab aktif dahulu dan kemudian memuatkan tab tersembunyi. Kerja pemaparan berulang dikurangkan dan input terminal diutamakan semasa output banyak.
