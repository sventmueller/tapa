Tapa 1.0.5 po reštarte znova zobrazí konverzáciu karty agenta vo vzdialenom pracovnom priestore.

## Opravy
- Po reštarte Tapy karta agenta vo vzdialenom pracovnom priestore znova ukazuje doterajšiu konverzáciu: Tapa číta prepis Claude z druhého počítača cez pripojenie pracovného priestoru. Karta sa spustí, keď je pripojenie otvorené, namiesto toho, aby najprv zlyhala.
- Karty Codex a OpenCode v dôveryhodnom pracovnom priestore sa pri otvorení Tapy už nespúšťajú dvakrát.
