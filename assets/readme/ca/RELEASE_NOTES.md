## Codex Remote Control

El botó del telèfon d’una pestanya nativa de Codex permet vincular el mòbil i continuar-hi la mateixa sessió quan acabi el torn actual. Disponible als espais de treball locals de confiança.

## Rendiment

L’obertura ràpida indexa els espais de treball en paral·lel i cancel·la les cerques superades mentre escrius. En restaurar una sessió, Tapa mostra primer la pestanya activa i carrega després les ocultes. El renderitzat fa menys feina repetida i l’entrada del terminal té prioritat quan hi ha molta sortida.
