يفتح Tapa 1.0.3 مساحات عمل على أجهزة كمبيوتر أخرى عبر SSH ويقترح الأوامر أثناء الكتابة.

## الجديد
- مساحات العمل البعيدة: يتيح «مساحة عمل جديدة» اختيار مجلد على كمبيوتر آخر: مضيف من `~/.ssh/config` أو عنوان، والمنفذ والمستخدم وكلمة المرور عند الحاجة، والمجلد هناك. تعمل الطرفيات والوكلاء المثبتون هناك على ذلك الكمبيوتر عبر اتصال SSH واحد. يمكن حفظ كلمة المرور في سلسلة المفاتيح، ولا يُقبل مفتاح مضيف غير معروف أبدًا دون تأكيد. قائمة الملفات ولوحة Git والمحرر والمعاينات غير متاحة هناك.
- يعرض الشريط الجانبي اتصال مساحة العمل البعيدة مع «إعادة الاتصال» و«قطع الاتصال» و«تعديل الاتصال». عندما يعود اتصال مفقود، تبدأ الطرفيات من جديد وتواصل علامات تبويب الوكلاء محادثتها.
- اقتراحات أثناء الكتابة: بدءًا من الحرف الثاني يظهر باقي الأمر المقترح باهتًا بعد المؤشر، ويقبله →. يقبل Tab اقتراحًا مؤكدًا أو يفتح قائمة إكمال تصف كل مرشح، مع حقل الإدخال أو بدونه.
- ألوان الأوامر: تأخذ الأوامر والأوامر الفرعية والخيارات والمتغيرات والعوامل ألوان السمة، ويظهر تحت الأمر الذي لا تستطيع الصدفة تشغيله خط أحمر متقطع. يوقف «الإعدادات › الإدخال» الاقتراحات والألوان.
- في علامة تبويب الوكيل، تفتح أزرار الوكلاء الفرعيين والعمليات في الخلفية و/tasks عرض نشاط يبيّن حالة كل عنصر ومدة تشغيله، مع «إظهار» و«إيقاف».

## التحسينات
- يمكن في «الإعدادات › عام › نافذة» إيقاف إعادة تسمية مساحة العمل بالنقر على اسمها.
- يعرض الشريط الجانبي عدد الملفات المتغيرة ثم زر Git ثم زر المجلد بهذا الترتيب، ولا يظهر زر Git إلا داخل مستودع Git.
