يستخدم Tapa 1.0.2 ذاكرة أقل عندما تكون علامات التبويب في الخلفية.

## التحسينات
- تحرّر علامات تبويب الطرفية المخفية مخازن Metal المؤقتة، وتحرّر علامات تبويب الوكلاء المخفية واجهات عرض المحادثات. تبقى جلسات الطرفية وسجل التمرير والمحادثات محفوظة.
- يعمل تبديل علامات التبويب والتمرير وتغيير الحجم بعبء أقل على الخيط الرئيسي. وتظل الواجهة سريعة الاستجابة أثناء استعادة مساحة العمل.
- يتعامل Claude وCodex مع الطلبات المنتظرة والردود بموثوقية أكبر.
