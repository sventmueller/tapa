يعرض Tapa 1.0.4 في علامات تبويب الوكلاء متى تكون مساحة العمل غير موثوق بها، ويطبّق تغيير الثقة على الوكلاء الذين يعملون بالفعل.

## التحسينات
- في مساحة عمل لم تثق بها، تعرض علامة تبويب الوكيل لـ Claude وCodex وOpenCode فوق حقل الإدخال أن إعدادات المشروع ومهاراته وخطافاته وخوادم MCP الخاصة به غير محمّلة، مع زر «الوثوق بمساحة العمل».
- عند الوثوق بمساحة عمل أو سحب الثقة منها، تبدأ جلسات الوكلاء المفتوحة فيها من جديد مع إعدادات المشروع أو بدونها. وتواصل محادثتها، ويكتمل الدور الجاري أولًا.
