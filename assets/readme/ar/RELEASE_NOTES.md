يلوّن Tapa 1.0.7 الأمر ويعرض قائمة الاقتراحات أثناء الكتابة، حتى بدون حقل الإدخال.

## الجديد
- بدون حقل الإدخال، يحصل الأمر الذي تكتبه على الألوان نفسها كما في الحقل: الأمر والأوامر الفرعية والخيارات والمتغيرات والعوامل، مع خط أحمر متقطع تحت الأمر الذي لا تستطيع الصدفة تشغيله. وتبقى الألوان التي تضعها الصدفة بنفسها.
- بدون حقل الإدخال، تفتح قائمة الاقتراحات من تلقاء نفسها أثناء كتابة كلمة. يشغّل Return السطر، ويقبل Tab أو → الاقتراح الرمادي؛ وبعد ↑ أو ↓ يقبلان العنصر المحدد. يغلق Esc القائمة لهذه الكلمة، ويوقفها «الإعدادات › الإدخال».

## التحسينات
- عند تثبيت وكيل واحد فقط، يفتحه زر الوكيل في شريط الأدوات بنقرة واحدة بدلًا من قائمة.
