O Tapa 1.0.7 colore o comando e mostra a lista de sugestões enquanto você digita, também sem o campo de entrada.

## Novidades
- Sem o campo de entrada, o comando que você digita recebe as mesmas cores do campo: comando, subcomandos, opções, variáveis e operadores, e um sublinhado vermelho tracejado sob um comando que o shell não consegue executar. As cores que o próprio shell define são mantidas.
- Sem o campo de entrada, a lista de sugestões abre sozinha enquanto você digita uma palavra. Return executa a linha e Tab ou → aceitam a sugestão cinza; depois de ↑ ou ↓, aceitam o item selecionado. Esc fecha a lista para essa palavra, e "Ajustes › Entrada" a desativa.

## Melhorias
- Com apenas um agente instalado, o botão de agente da barra de ferramentas o abre com um clique em vez de um menu.
