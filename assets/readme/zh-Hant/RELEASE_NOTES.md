Tapa 1.0.3 可透過 SSH 開啟其他電腦上的工作區，並在你輸入時建議指令。

## 新功能
- 遠端工作區：「新增工作區」可以選擇另一台電腦上的檔案夾：來自 `~/.ssh/config` 的主機或一個位址，必要時填寫埠號、使用者和密碼，以及那裡的檔案夾。終端機和那裡安裝的代理程式會透過同一個 SSH 連線在那台電腦上執行。密碼可以儲存在鑰匙圈中，未知的主機金鑰未經確認絕不會被接受。檔案列表、Git 面板、編輯器和預覽在那裡無法使用。
- 側邊欄會顯示遠端工作區的連線，並提供「重新連線」「中斷連線」和「編輯連線」。中斷的連線恢復後，終端機會重新啟動，代理程式標籤頁會繼續對話。
- 輸入時的建議：從第二個字元起，建議指令的其餘部分會以淡色顯示在游標之後，按 → 即可採用。Tab 會採用確定的建議，或打開描述每個候選項目的補齊選單，有無輸入欄位皆可使用。
- 指令著色：指令、子指令、選項、變數和運算子會使用主題顏色，shell 無法執行的指令會加上紅色虛線底線。「設定 › 輸入」可關閉建議和著色。
- 在代理程式標籤頁中，子代理程式和背景程序按鈕以及 /tasks 會打開活動檢視，顯示每個項目的狀態和執行時間，並提供「顯示」和「停止」。

## 改進
- 「設定 › 一般 › 視窗」可關閉按一下名稱以重新命名工作區。
- 側邊欄會依序顯示已更改檔案的數量、Git 按鈕和檔案夾按鈕，且只在 Git 儲存庫中顯示 Git 按鈕。
