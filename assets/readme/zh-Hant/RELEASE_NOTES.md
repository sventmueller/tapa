Tapa 1.0.0 是第一個以磁碟映像檔發佈的版本：打開 `Tapa-1.0.0.dmg`，然後將 Tapa 拖到「應用程式」檔案夾即可。Tapa 0.1.0 會自行更新到此版本，Homebrew 安裝的也是同一個映像檔。

## 新功能
- 關閉 Tapa 的最後一個視窗會結束 Tapa 並保留一切：工作區、標籤頁、分割、歷史記錄和代理程式工作階段會在下次啟動時回復成你離開時的樣子。只有在仍有 Shell 以外的程式在執行時，Tapa 才會先詢問。
- 在側邊欄中拖移工作區，可依任意順序排列；「終端機」永遠保持在最上方。
- 新視窗會以你最後調整過大小的視窗的尺寸和側邊欄寬度開啟，即使 Tapa 沒有回復任何視窗也是如此；Tapa 也會記住是否顯示輸入欄位。
- 當 Tapa 以收合的側邊欄啟動時，「新增工作區」按鈕會保持隱藏。
- 程式成批寫出的輸出會在程式暫停時顯示，最多延遲 8 毫秒，因此畫到一半的畫面不再閃爍。
- 每個工作階段都執行在 Tapa 自己的終端機核心上；切換到 Alacritty 核心的設定已移除。
- 輸入欄位上方的檔案夾和分支是純灰色文字，與預留位置文字對齊。
- 在代理程式標籤頁中，`/resume` 會列出該代理程式在此檔案夾中的過往工作階段，並在單獨的標籤頁中繼續其中一個。
- 代理程式標籤頁浮層中的長列表會捲動，而不是讓視窗變高。
- 代理程式只有在閒置三秒後才算完成，因此它的狀態不再在各步驟之間閃爍。
- 在全螢幕下，側邊欄會留在工具列下方，並在選單列出現時隨工具列一起下移。

## Tapa 一覽
- 側邊欄中的工作區，每個都有自己的標籤頁、分割、代理程式、編輯器和瀏覽器標籤頁；視窗和代理程式工作階段在重新啟動後會回來。
- 用於 Claude、Codex、OpenCode 以及登錄庫中任何 ACP 代理程式的代理程式標籤頁，可在設定中安裝、更新及退回舊版本。
- 檔案面板和 Git 面板、Markdown 和圖片預覽，以及支援聽寫的指令輸入欄位。
- 淺色、深色或跟隨系統的外觀、四種字體大小、35 種介面語言。
